# Atualizar para V9

1. Faça backup do projeto e banco.
2. Copie os arquivos da V9 sobre o projeto atual.
3. Mantenha seu `.env` do Render/local.
4. Rode `npm install`.
5. Rode `npm start` e confirme `/health`.
6. Commit/push para o GitHub e aguarde o Render.

Novas rotas: `/assinatura` e `/historico`.
